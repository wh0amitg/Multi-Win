Drop logo PNGs here. They are copied next to Multi-Win.exe on build.

  windows.png  - Windows rows in the image list
  kali.png     - Kali Linux rows
  linux.png    - other Linux rows (Tux etc.)
  generic.png  - unknown ISOs
  app-logo.png - YOUR app logo: header inside the app (run make-icon.ps1 after,
                 it regenerates app.ico = exe + taskbar icon)

Square PNGs 48-128px work best (shown at 28px).
Missing files fall back to built-in vector icons, so the app works without them.
