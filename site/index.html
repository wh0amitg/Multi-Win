Возможности

Что умеет программа

Одна задача — подготовка установочного носителя Windows или Linux. Каталог, запись, проверки и журнал в одном окне.

каталог

ISO из списка, с диска или по ссылке

Vista / 7 / 8.1 / 10 / 11 с прямыми ссылками на загрузку. Свой .iso определяется по содержимому образа (install.wim, загрузчики, .disk/info), а не только по имени файла. Поддерживается перетаскивание файла на окно.

windows 11

Обход проверок и твики установки

Опции autounattend: BypassTPMCheck, SecureBoot, CPU, RAM, пропуск сетевого экрана и Microsoft-аккаунта, локальный пользователь, пропуск вопросов приватности, запрет автошифрования BitLocker.

запись

Режимы под тип образа

Windows — файловое копирование: MBR или GPT, FAT32 с автонарезкой install.wim через DISM или NTFS без нарезки. Linux — побайтовая (raw) запись. Предупреждение, если носитель меньше образа.

контроль

Проверки и диагностика

Проверка поверхности перед записью, пофайловая или побайтовая сверка после, замер скорости USB, проверка совместимости железа с Windows 11, живой прогресс: скорость, объем, ETA, журнал.

без флешки

Установка без USB

Файлы установки Windows копируются в папку MULTIWIN-SETUP на внутреннем диске, создается разовая загрузочная запись (bootsequence). После перезагрузки запускается Setup, затем папка и запись удаляются.

порядок

Кэш, метки, журнал

Загруженные ISO хранятся в %TEMP%\Multi-Win, есть очистка кэша. Своя метка тома, автообновление списка USB, сохранение журнала в файл.

Установка без флешки — как это работает

Режим «Этот ПК» для случаев, когда USB-накопителя нет. Поддерживаются только установочные образы Windows (с sources\boot.wim).

  1. Выберите образ и внутренний диск с запасом: размер ISO + 512 МБ.
  2. Нажмите «Install to this PC». Файлы копируются в \MULTIWIN-SETUP, создается разовая запись загрузки. Основная запись не меняется.
  3. Перезагрузитесь — один раз загрузится Setup. После установки удалите папку кнопкой «Remove setup» или файлом remove-hdd-setup.cmd.
Использование

Три шага

01

Образ

Встроенный список, локальный файл или прямая http(s)-ссылка на .iso. Для локальных файлов выполняется анализ содержимого.

02

Носитель

USB-накопитель (схема разделов, файловая система, метка, проверки) или внутренний диск в режиме без флешки. Запись на USB стирает все данные, выводится подтверждение.

03

Запись

Загрузка (с докачкой и повторами), проверка SHA256 при наличии хеша, запись, сверка. Прогресс, скорость и журнал отображаются в реальном времени, есть отмена.

Скачивание и сборка

Исходный код и сборка

Требуются Windows 10/11 x64, права администратора для записи и .NET 8 SDK для сборки.

Открыть GitHub README
git clone https://github.com/wh0amitg/Multi-Win.git
cd Multi-Win
# обычная сборка
dotnet build
# один .exe для систем без .NET (~190 МБ):
dotnet publish -c Release -p:PublishProfile=win-x64-selfcontained

Ссылки каталога указывают на зеркала archive.org. По возможности сверяйте SHA256. Запись на USB стирает данные, программа показывает предупреждение. Результат сборки ищет Data/catalog.json и Assets рядом с exe.

FAQ

Частые вопросы

Программа проверяет CPU, RAM, TPM и UEFI и показывает предупреждение о несовместимости. Обход проверок доступен как опция, обновления на несовместимом железе не гарантируются.

FAT32 с нарезкой — вариант по умолчанию: совместим с BIOS и UEFI. NTFS без нарезки быстрее, подходит для BIOS и UEFI с поддержкой NTFS. Схема разделов: MBR для BIOS+UEFI, GPT только для UEFI.

Да, образы не-Windows записываются побайтово (raw). Тип определяется по содержимому ISO. Режим установки без флешки работает только с Windows.

Кнопкой «Remove setup» в программе или файлом MULTIWIN-SETUP\remove-hdd-setup.cmd от администратора. Удаляются папка и разовая загрузочная запись.
